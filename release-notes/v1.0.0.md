## distro-match v1.0.0

First tagged release — a static site that recommends a Linux
distribution through a guided questionnaire: 12 questions about use
case, hardware, experience, and preferences, scored against 62
hand-curated distro entries. Astro static build, deployed to
Cloudflare Pages.

### Highlights

- **Correct recommendations.** Neutral multi-select answers ("not
  sure", "no preference") no longer score as zero for every distro —
  the worst bug a recommender can have, inverted preferences included.
  The desktop-environment tie-break now actually runs (it was
  comparing mismatched vocabularies and never fired). Hardware floor
  thresholds fixed so low-spec machines get realistic suggestions.
- **Accurate data.** Factual corrections across entries: BigLinux is
  Arch/pacman (was Ubuntu/apt), Kodachi is Ubuntu-based (was Debian),
  discontinued Clear Linux removed, architecture claims corrected.
  All 153 `similar_distros` references resolve to real entries.
  Versions verified against upstream sources 2026-11-17 — Fedora 45,
  RHEL/Rocky/Alma 10.3, Tails 7.17, Vanilla OS 3, and friends.
- **Real security headers.** Deployment moved headers to Cloudflare
  Pages `_headers` — the Astro middleware that was supposed to emit
  them never ran under static output. JSON data islands are escaped
  against `</script>` breakout and distro fields get schema
  validation in tests.
- **Fresh stack.** Astro 7.4.7, Vite 8, Vitest 4, Zod 4 — the queued
  security advisories (XSS-class Astro fixes included) are all merged.
- **Honest docs.** README/CONTRIBUTING now match reality: Node 22+,
  Astro 7, Tailwind 4, 12 wizard questions.

### Upgrade notes

First release — nothing to upgrade from. Requires **Node ≥22.23.4**
(astro engine floor). Local run: `npm ci && npm run dev`. Build:
`npm run build` → `dist/`. Deploy: `wrangler pages deploy dist`
(manual; the site has no deploy pipeline).
